# 📰 Fake News Detection

A complete **Machine Learning** project for detecting fake news using **NLP** techniques and classical ML models.

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white) ![scikit-learn](https://img.shields.io/badge/scikit--learn-%23F7931E?style=for-the-badge&logo=scikit-learn&logoColor=white) ![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white)

## ✨ Features
- Advanced text preprocessing
- Exploratory Data Analysis (EDA)
- TF-IDF Vectorization
- Training multiple ML models
- Model comparison & evaluation
- Interactive **Streamlit** web application

## 🛠 Tech Stack
- **Python 3.9+**
- pandas, numpy
- scikit-learn, XGBoost
- NLTK for text processing
- Streamlit for UI

## 🚀 Quick Start

```bash
git clone https://github.com/mohamedx101/Fake-News-Detection.git
cd Fake-News-Detection
pip install -r requirements.txt
streamlit run app.py
```
